# Vishing a hlasové deepfaky

## O projektu

Tento projekt se zabývá vishingem a deepfaky. Zaměřuje se hlavně na to, jak lze pomocí umělé inteligence vytvořit nebo napodobit lidský hlas a jak se toho dá využít při telefonních podvodech.

Okrajově se podíváme také na klasické deepfaky, například falešná videa, fotografie nebo upravené obrázky vytvořené pomocí AI.

Cílem je zjistit, jak tyto technologie fungují, jaká rizika představují a jak se proti podobným podvodům bránit.

## Na co se zaměříme

- **Vishing** – podvody přes telefon a vydávání se za jiné osoby.
- **Hlasové deepfaky** – vytváření falešných hlasů pomocí AI.
- **Klonování hlasu** – napodobování hlasu konkrétní osoby.
- **Klasické deepfaky** – falešná videa, fotografie a obrázky vytvořené nebo upravené pomocí AI.
- **Rozpoznávání deepfaků** – jak poznat skutečný obsah od uměle vytvořeného.
- **Ochrana** – jak se vyhnout podvodům a manipulaci.

## Cíle projektu

- Zjistit, jak funguje klonování hlasu.
- Ukázat možnosti využití hlasových deepfaků.
- Vyzkoušet rozpoznávání uměle vytvořených hlasů.
- Představit rizika vishingových útoků.
- Stručně představit i další druhy deepfaků.
- Ukázat, jak se proti těmto podvodům chránit.

## Etika

Projekt slouží pouze ke vzdělávacím účelům. Při testování nebudeme bez souhlasu používat hlasy skutečných osob ani cílit na skutečné lidi.
